## 2. 对齐 skill 的条款

| skill 条款 | 我们对齐方式 |
|---|---|
| **三把锁**(Color / Shape / Theme Consistency) | 全站**一个** accent(= 你们的绿)、**一套**圆角、**单一**深色主题;任何引用只用 tokens |
| **Hero discipline**(≤2 行标题、副文案 ≤20 词、主 CTA 免滚动、导航单行 ≤80px) | 首屏必须有一个主导物(真实对照图)+「开始捕获」在首屏;顶栏单行 |
| **Anti-slop 禁令** | 禁渐变/紫色/AI 网格渐变、玻璃拟态、装饰状态点、emoji、三张等宽卡片、假产品 UI(div 拼的假 dashboard)、每行边框、em dash |
| **Dark mode protocol** | off-black / off-white(非纯黑纯白),对比度 ≥4.5:1 |
| **Redesign protocol §11** | 审计先行(§1)、模式=preserve、URL/导航文案/字段名不静默变更(§5 列出既有改动) |
| **Imagery** | 图片=产品自己的产物(捕获截图、heatmap);不造假界面、不用 stock 图充数 |
| **Pre-flight** | `lint.mjs` 0 FAIL;**`inspect.mjs` 在 1440/768/390 全部 0 FAIL**,且**登录页与控制台各跑一次** |

## 4. 视觉规范(确认后固化为 tokens)

| 维度 | 取值 | 说明 |

## 5. 交互与状态(必须有)

- 每个控件有 hover / press / focus-visible 反馈;焦点环 2px accent
- 任务状态四态:排队 / 进行中 / 完成 / 失败(实时:SSE,断线由 4s 轮询兜底)
- **空态**三处:无任务、无验证记录、未提交还原工程 —— 各一句人话 + 一个动作
- **错误态**原样透出原因:构建失败输出、配额不足、邮箱未验证、域名封禁
- 手机 390px:顶栏单行不换行;账本行带 16:10 缩略图;表单控件 44px 高
- 无障碍:真实 `<label>`、`alt`、`aria-*`、键盘可达、`prefers-reduced-motion` 下内容照常可见

**既有文案改动声明(Redesign protocol 要求显式):**
导航「任务 / 管理」**未改**;表单字段 id(`source`/`type`/`viewports`/`maxNodes`/`dynamic`/`states`)**未改**;
标签从「URL/视口宽度(逗号分隔)」微调为「页面地址/视口宽度(逗号分隔)」。如需完全回退到原标签,说一声。

## 6. 需要你拍板的 4 件事

1. **主色**:恢复 `#4ade80` 绿为唯一 accent?（我建议:是）
2. **字体**:
   - A 系统 UI 字体栈(中文最稳、零外部依赖、最快)
   - B Switzer 用于拉丁/数字 + 系统中文字体(有设计感,混排需微调)
   - C 自托管 Noto Sans SC(统一,但 +1~2MB)
   我建议 **A**(可靠性优先;视频/截图里的中文不会再有任何"乱码"风险)。
3. **根路径**:本期是否顺带做公开落地页(S4),把控制台挪到 `/app`?
   （docs 要求 URL 变更必须显式确认,所以先问;不做的话 `/` 仍是登录页)
4. **表格线条**:文档禁"每行边框",但 SKILL.md 的 house rules 允许**真表格**保留线。
   我建议:真表格(用户/审计/差异)**保留细线并声明例外**;其余列表改**带状/卡片**。你也可要求全部改带状。
