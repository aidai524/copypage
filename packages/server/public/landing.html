拖动滑块比较两边。两张图是同一视口下工具自己截的，不是设计稿。

这组数字来自工具在本地 fixture 上的真实运行：41 个资产可用、3 个失败被记下、1873 个 DOM 节点、0 个动态区域。

它做三件事。

捕获
打开目标页，等它稳定，把 DOM、样式、字体和图片取下来。轮播、计时器、随机数会被冻结，会动的区域单独记进 dynamic.json。
收敛
逐视口比对像素，按差异位置改代码，重复到低于阈值。改不掉的差异画成热力图交给你，而不是藏起来。
交付
输出能跑的 React 工程：组件、样式、本地化资产，外加一份带截图与热力图的验证报告。

不一样的地方，它会告诉你。

  • 结构相似度 SSIM0.9997
  • 像素差异0.03%
  • 资产可用 / 失败41 / 3
  • 动态区域0
  • DOM 节点1873

我们不承诺 100% 一致。动态内容、第三方组件和跨域字体会被标出来，你会看到它在哪里没对齐，以及为什么。

拿到的是工程，不是截图。

/** @region 0/1 (section.hero > div.hero-bg, h1, button.cta) */
export function Hero() {
  return (
    <section className="hero">
      <div className="hero-bg" />
      <h1>Clone me if you can</h1>
      <button className="cta" type="button">
        Get Started
      </button>
    </section>
  )
}
  • src/components 下每个组件都带 @region 注释，指回原站对应的区域
  • 样式与 tokens 跟着工程走，public/assets 里的图片已经本地化
  • npm install 之后 npm run dev 就能打开，不需要再连回原站
