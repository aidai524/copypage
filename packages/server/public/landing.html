三步，从网址到工程。

捕获
打开目标页，等它稳定，再把 DOM、样式、字体和图片取下来。轮播、计时器和随机数会被冻结，会动的区域单独记录，不算作差异。
收敛
在每个视口下比对像素，按差异的位置修改代码，重复到差异低于阈值。实在改不掉的部分会画成热力图交给你，不会藏起来。
交付
你拿到一个能跑的 React 工程：组件、样式和本地化好的图片，外加一份带截图与热力图的验证报告。

适合什么，不适合什么。

适合

  • 把旧站、营销页迁移到 React，先拿到一份可对照的起点
  • 给设计师或外包一份“现在线上长什么样”的基准
  • 要对比改版前后页面，需要量化的差异报告

不适合

  • 需要登录才能看到的页面，Kloon 只访问公开网址
  • 想原样搬走别人的内容或品牌，请确认你有权使用
  • 强依赖后端数据的功能，它还原的是页面外观，不是业务逻辑
